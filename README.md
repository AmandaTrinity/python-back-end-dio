# 🐍 Exercícios do Curso Back-End com Python — Santander Open Academy

Este repositório reúne os exercícios que estou desenvolvendo durante o curso de **Back-End com Python**, promovido pelo **Santander** em parceria com a **DIO**.

## 🎯 Objetivo

Explorar, praticar e consolidar os principais fundamentos do desenvolvimento back-end com foco em **Python**, incluindo:

- Lógica de programação aplicada ao back-end  
- Manipulação de arquivos e dados  
- Programação orientada a objetos  
- Construção de APIs
- Boas práticas de organização de código e testes

## ⚙️ Tecnologias

- Python  
- Git e GitHub
